# MuslimOS Beta

> BismiLLAH Ar-Rahman Ar-Raheem.

An all-in-one launcher for practical daily Muslim life, built with BirrStack.

## 25+ Mini Apps

### Ibadah (Worship)
- Quran, Hadith, Prayer Times, Qibla, Tasbih, Duas, 99 Names, Zakat

### Knowledge
- Hijri Calendar, Islamic Events, Library

### Tools
- Compass, Calculator, Notes, Reminders, Timer, Flashlight, Weather, Audio Player

### Lifestyle
- Mosque Finder, Halal Food, Settings

### Social
- Community, Favorites

## Quick Start

```bash
npm install
npm run dev
npm run build
```
